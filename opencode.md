# OpenCode Configuration for GatePay

## Project Overview
Full-stack payment verification platform. Next.js 16 App Router + Turbopack + Convex backend.

## Dev Commands
- `npm run dev` — start Next.js dev server on port 8080
- `npx convex dev` — sync Convex functions with dev deployment (separate terminal)
- `npm run build` — production build (Turbopack)
- `npx convex deploy` — deploy Convex functions to production

## Key Conventions

### Routes (Next.js App Router)
- Pages in `app/` directory with file-based routing
- Admin routes under `app/admin/` with shared layout (auth guard + sidebar)
- Public API routes under `app/api/v1/public/`
- Pay portal under `app/pay/`
- All page components use `"use client"` for Convex hooks

### Convex Backend
- Schema: `convex/schema.ts` (11 tables)
- Auth: `convex/auth.ts` (signUp, signIn, getMe with DB session store)
- Public API: `convex/public.ts` (verifyTransaction, submitTransaction, triggerVerifyBatch)
- Rate limiting: DB-based in `convex/rate_limit.ts`
- All mutations/queries in `convex/` submodules by domain

### Convex Client Integration
- Client provider: `src/integrations/convex/provider.tsx`
- Server HTTP client: `src/integrations/convex/server.ts`
- Auth middleware: `src/integrations/convex/auth.ts`
- Session token stored in localStorage key `gk_session_token`

### Auth
- DB-backed sessions with SHA-256 password hashing
- Login page at `/login` with sign-in/sign-up
- Roles: `super_admin` > `admin` > `member`
- Admin layout calls `getMe` on mount to validate session

### Components
- UI primitives in `src/components/ui/` (shadcn — do not edit directly)
- Site components in `src/components/site/`
- Sidebar: `src/components/admin/Sidebar.tsx` (mobile responsive with hamburger drawer)
- Use `cn()` from `src/lib/utils.ts` for class merging
- Use Lucide icons for UI elements

### Validation (`src/lib/validation.ts`)
- Zod schemas for all forms and API inputs
- `sanitizeText()` for free-text input sanitization
- `payCodeSchema` for 6-char payment codes
- `paymentSubmissionSchema` for bKash payment submissions

### Email (Resend)
- Confirmation emails sent after admin verifies payment
- API key: `RESEND_API_KEY` env var
- From: `GatePay <noreply@darvizlabs.com>`
- Called from `convex/public.ts` in `triggerVerifyBatch`

### API (public)
- `POST /api/v1/public/transactions/verify` — Bearer token auth
- `POST /api/v1/public/transactions/submit` — Bearer token auth
- Rate limited (30/60 req/min/IP via Convex + per-key limits)
- HMAC-SHA256 callback signing
- Handlers in `app/api/v1/public/*/route.ts`

### Homepage
- `app/page.tsx` — Pixel Perfect Landing design adapted for GatePay
- ClashDisplay font (`public/fonts/ClashDisplay-Variable.woff`)
- Color system in `app/globals.css` (neon blue primary, ink dark sections)

### Files not to edit manually
- `convex/_generated/` (auto-generated by `npx convex dev`)
- `src/components/ui/*` (shadcn — regenerated via components.json)
- `.next/types/` (auto-generated by Next.js)
