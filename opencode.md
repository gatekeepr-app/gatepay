# OpenCode Configuration for Gatekeepr

## Project Overview
Full-stack business management platform. React 19 + TanStack Start + Convex + Cloudflare.

## Dev Commands
- `bun dev` — start dev server
- `npx convex dev` — start Convex dev server (separate terminal)
- `bun build` — production build
- `bun preview` — preview production build
- `bun lint` — run ESLint
- `bun format` — run Prettier

## Key Conventions

### Routes (file-based, TanStack Router)
- Public routes go directly in `src/routes/`
- Admin routes use `_admin` layout wrapper
- Route files use snake-case or camelCase filenames
- See `src/routeTree.gen.ts` for the full route tree

### Convex Backend
- Schema: `convex/schema.ts` (11 tables)
- Auth: `convex/auth.ts` (signUp, signIn, getMe with in-memory session store)
- Public API: `convex/public.ts` (verifyTransaction, submitTransaction — per-key scoped)
- Rate limiting: `convex/rate-limit.ts` (in-memory burst + Convex distributed)
- All mutations/queries in `convex/` submodules by domain

### Convex Client Integration
- Client provider: `src/integrations/convex/client.ts`
- Server HTTP client: `src/integrations/convex/server.ts`
- Auth middleware: `src/integrations/convex/auth.ts`
- Session token stored in localStorage key `gk_session_token`

### Auth
- Simple in-memory session store (SHA-256 password + random token)
- Login page auto-provisions users on first signup attempt
- Roles: `super_admin` > `admin` > `member`
- Admin layout calls `getMe` on mount to validate session

### Components
- UI primitives in `src/components/ui/` (shadcn — do not edit directly)
- Site components in `src/components/site/`
- Use `cn()` from `src/lib/utils.ts` for class merging
- Use Lucide icons for UI elements

### Validation (src/lib/validation.ts)
- Zod schemas for all forms and API inputs
- sanitizeText() for free-text input sanitization

### API (public)
- `POST /api/public/transactions/verify` — Bearer token auth
- `POST /api/public/transactions/submit` — Bearer token auth
- Rate limited (30/60 req/min/IP via Convex)
- HMAC-SHA256 callback signing
- Handlers in `src/routes/api/public/` (TanStack Start route handlers)

### Files not to edit manually
- `src/routeTree.gen.ts` (auto-generated)
- `convex/_generated/` (auto-generated by `npx convex dev`)
- `src/components/ui/*` (shadcn — regenerated via components.json)
